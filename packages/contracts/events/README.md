# События между сервисами

JSON-схемы доменных событий RabbitMQ. HTTP-контракты описывает OpenAPI (Scramble), события — только эти файлы.

- `envelope.schema.json` — общий конверт (`event_id`, `type`, `schema_version`, `occurred_at`, `correlation_id`, `payload`).
- `<тип>.schema.json` — схема `payload` конкретного события.

## Правила совместимости

- Добавление необязательного поля в `payload` — совместимое изменение, но схемы закрыты (`additionalProperties: false`), поэтому поле нужно описать в схеме в том же изменении.
- Удаление или переименование поля, изменение типа или смысла — несовместимо: повышайте `schema_version`, пока потребители поддерживают обе версии.
- Потребитель обязан быть идемпотентным по `event_id` (inbox) и отклонять неизвестную `schema_version` без повторов (в dead-letter очередь).
- Проверка: `pnpm test:unit` (`tests/unit/event-contracts.test.ts`) валидирует примеры против схем.
