# Токены в HttpOnly cookie и CSRF

**Статус:** принято, 13 октября 2026.

## Контекст

Браузерные клиенты (Nuxt SSR и Vue-админка) должны входить в систему, не храня токены в JavaScript.

## Решение

Access JWT (15 минут) и непрозрачный refresh-токен (30 дней, в базе только хеш) передаются в HttpOnly cookie. Изменяющие запросы защищены подписанным CSRF-токеном и проверкой Origin; refresh атомарно ротируется, повторное использование погашенного токена отзывает семейство. Роль и блокировка берутся из базы при каждом запросе, а не из JWT.

## Последствия

XSS не может прочитать токены; клиент обязан отправлять `X-CSRF-TOKEN` (общий `api()` делает это и один раз обновляет токен при 419). Отзыв действует сразу. Цена: каждому запросу нужна проверка в Identity.

## Альтернативы

Токены в `localStorage`/Bearer-заголовке — проще для API, но уязвимы для XSS.
