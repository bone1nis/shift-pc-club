# Текущий статус реализации

Все семь этапов выполнены для локального демо (на 13 октября 2026 года). Не входит в охват и требует реальной среды: холодный старт по README на чистой машине, запуск CI в самом CI, выбор хостинга и публикация. Подробный журнал проверок ведётся локально у разработчика и в репозиторий не входит.

| Этап                     | Состояние | Что сделано                                                                                                                                                           |
| ------------------------ | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Спецификация и каркас | Готов     | Монорепозиторий, три сервиса Laravel, Nuxt и Vue, прокси, мониторинг, Compose (dev и `prod`).                                                                         |
| 2. Данные и авторизация  | Готов     | JWT в HttpOnly-cookie, ротация refresh, CSRF, роли, восстановление пароля; формы проверяются в браузере (Zod) и на сервере.                                           |
| 3. Бронирование          | Готов     | Бронь в одной транзакции, outbox/inbox, идемпотентность, конкурентные тесты; сбой воркера посреди обработки проверен на живом стеке (`scripts/chaos-worker-kill.sh`). |
| 4. Зал и игровые сессии  | Готов     | Заселение, гостевые сессии, продление, пересадка, оплата, обслуживание места, неявка и напоминания; тесты и E2E.                                                      |
| 5. Лендинг и кабинет     | Готов     | Лендинг с анимациями, бронирование, кабинет, SEO, PWA; адрес и контакты демонстрационные.                                                                             |
| 6. Настройки и отчёты    | Готов     | Профиль клуба, тарифы, отчёты, CSV для Excel, уведомления, аудит, дашборды Grafana.                                                                                   |
| 7. Подготовка демо       | Готов     | E2E на Chromium и Pixel 7, `scripts/check.sh all`, сценарии восстановления, README и руководства.                                                                     |

Подтверждающие проверки: `scripts/check.sh all` (форматирование, lint, типы, unit с покрытием, сборка, Pint, PHPStan, backend-тесты) и `pnpm test:e2e` (Playwright, Chromium и Pixel 7).
