# Жалобы: ключ владельца и код восстановления

Раздел «Жалобы» в админке (`/admin/`) доступен только роли `owner`. Администратор его не видит, а его запросы к API получают 403. Все жалобы зашифрованы под ключ владельца, и без него никто, включая сервер, их не прочитает.

## Первый вход: создать ключ

1. Войдите владельцем (локально `owner@shift.local`) и откройте «Жалобы».
2. Нажмите «Создать ключ». Приватный ключ остаётся в браузере и не покидает его, на сервер уходит открытый ключ и зашифрованная копия.
3. Появится **код восстановления**. Он показывается один раз. Запишите его на бумагу и спрячьте, не храните его на том же устройстве. Подтвердите, что записали.
4. Покажите игрокам отпечаток ключа (12 групп по 5 цифр): сообщите лично или напечатайте в клубе. Игроки сверяют его с формой жалобы.

## Читать жалобы

В списке видны категория, оценка, статус и дата. Текст расшифровывается в вашем браузере при открытии. Статусы: новая, прочитана, закрыта. Бейдж новых жалоб в меню обновляется сам. О каждой новой жалобе на почту приходит письмо «Новая жалоба или отзыв» только с номером и ссылкой на раздел «Жалобы»: текст в письме не передаётся, его можно прочитать только в админке. Письмо может не дойти, поэтому ориентируйтесь и на бейдж.

## Новое устройство: восстановить ключ

1. Откройте «Жалобы» на новом устройстве, выберите «Восстановить ключ».
2. Введите код восстановления. Браузер скачает зашифрованную копию и расшифрует её кодом.
3. Жалобы снова читаются.

## Потерян код восстановления

Если ключ есть на сервере, а на устройстве его нет и кода тоже нет, на экране «Восстановить ключ» нажмите «Не помню код — создать новый ключ» (сначала отметьте, что понимаете последствия). Это обычная смена ключа: появится новый код восстановления, показанный один раз. Жалобы, зашифрованные прежним ключом, прочитать будет нельзя, новые пойдут под новый ключ. Старый ключ остаётся на сервере в истории.

## Сменить ключ

«Сменить ключ» нужно, если подозреваете утечку. Новые жалобы идут под новый ключ, старые читаются старым. У каждого ключа свой код: на чистом устройстве старые жалобы откроются только старым кодом, храните все. После смены сообщите игрокам новый отпечаток, пока они его не знают, форма будет их предупреждать.

## Чего не сделать

- **Потеряли устройство и код — жалобы потеряны.** Сервер помочь не может, это и есть E2E.
- Ключ non-extractable не защищает от вредоносного скрипта на странице: работайте только с доверенных устройств.
- Утечка приватного ключа раскрывает все жалобы под ним (нет forward secrecy).

Полный список ограничений — в README проекта (раздел «Ограничения модели безопасности»).
